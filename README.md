# 遊戲連點器 (gameclicker)

桌面滑鼠連點器，附圖形介面與全域熱鍵，針對打遊戲加了不少功能。

## 安裝與執行
```
pip install -r requirements.txt
python autoclicker.py
```
（需要 Python 3.8+，Windows / macOS / Linux(X11)；macOS 需在「輔助使用」授權終端機。
Windows 想不跳黑視窗，可用 `pythonw autoclicker.py` 或做成捷徑。）

## 功能
**基本**
- 滑鼠連點：間隔（毫秒）、隨機抖動、次數（0 = 無限）、左 / 右 / 中鍵、單擊或雙擊
- 鍵盤連按：可指定任一按鍵（如 `space`、`e`、`1`），也能用逗號輪流按，例如 `1,2,3`
- **按住模式**：持續按住某個鍵或滑鼠鍵（例如按住 `w` 自動前進），停止時一定會放開
- 固定座標點擊、啟動倒數、即時顯示點擊次數與 CPS

**打遊戲用**
- **設定檔**：每個遊戲存一組設定，內建四個範例（放置遊戲、按住才連點、技能輪放、按住 W）
- **只在指定視窗運作**：填入遊戲視窗標題（按記錄視窗熱鍵可自動抓），切到別的視窗會自動暫停，切回來繼續（Windows）
- **熱鍵可自訂**，支援滑鼠側鍵；可選「按住熱鍵才連點」，放開就停
- **遊戲相容模式**：用掃描碼送出按鍵，部分遊戲才收得到（Windows）
- 按下持續時間可調（部分遊戲點太快會漏）、時間上限、開始 / 停止提示音（Windows）

**預設熱鍵**：**F6** 開始/停止、**F7** 結束程式、**F8** 記錄座標、**F9** 記錄目前視窗標題

設定自動儲存於 `~/.gameclicker.json`，設定檔存於 `~/.gameclicker_profiles.json`。

## 注意
部分線上遊戲禁止使用自動化工具，使用前請確認遊戲規範，風險自負。
