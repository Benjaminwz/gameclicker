# 遊戲連點器 (gameclicker)

簡單的桌面滑鼠連點器，附圖形介面與全域熱鍵。

## 安裝與執行
```
pip install -r requirements.txt
python autoclicker.py
```
（需要 Python 3.8+，Windows / macOS / Linux(X11)；macOS 需在「輔助使用」授權終端機。）

## 功能
- 點擊間隔（毫秒）、隨機抖動、點擊次數（0 = 無限）
- 左 / 右 / 中鍵、單擊或雙擊
- 全域熱鍵：**F6** 開始/停止、**F7** 結束程式

## 注意
部分線上遊戲禁止使用自動化工具，請自行確認遊戲規範，風險自負。
